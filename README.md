# Agentic Software Engineering

## Building Reliable Software with AI Agents

English | فارسی

---

This repository contains the book **Agentic Software Engineering**.

The book explores a new approach to software development where humans and AI agents collaborate through:

- Specifications
- Engineering artifacts
- Context engineering
- Validation
- Governance

The goal is not simply generating more code.

The goal is building reliable software systems with AI agents.

- AI Agent Workflows

## Aegis Vision

Aegis is a proposed governance layer for AI-assisted software engineering.

It aims to provide:

- Traceability
- Policy enforcement
- Artifact validation
- Compliance reporting

between AI agents and software projects.
