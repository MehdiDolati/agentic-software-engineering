# Observation

Over the past decades, software engineering has continuously evolved in response to increasing system complexity.

Programming evolved into software engineering.

Software engineering evolved into Agile.

Agile evolved into DevOps.

DevOps evolved into Cloud-Native Engineering.

Today, AI agents are driving the next transformation.

---

# Working Hypothesis

The fundamental transformation is **not** the introduction of AI.

The deeper transformation is the gradual shift from implicit engineering knowledge toward explicit, structured, and manageable engineering artifacts.

Every major evolution in software engineering has increased the explicit representation of engineering knowledge.

Examples include:

- Requirements documents
- Design models
- Source code
- Test suites
- CI/CD pipelines
- Infrastructure as Code
- Architecture Decision Records
- Specifications
- Policies

AI agents accelerate this trend because they rely on explicit knowledge to collaborate effectively with humans.

---

# Proposed Thesis

Software engineering is evolving from a **code-centric discipline** toward an **artifact-centric discipline**.

In this new paradigm:

- Code becomes one artifact among many.
- Specifications become executable engineering intent.
- Context becomes an engineering asset.
- Governance becomes continuous.
- AI agents become engineering participants rather than simple tools.

---

# Implications

If this thesis is correct:

- Agentic Software Engineering is one consequence of Artifact-Centric Engineering.
- Governance operates over artifact lifecycles rather than only source code.
- Knowledge management becomes a first-class engineering concern.
- Engineering teams design artifact ecosystems instead of codebases alone.
