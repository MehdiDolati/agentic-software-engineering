# Citation Policy

## Goal

The book follows a research-informed engineering approach.

References are included to:

- acknowledge prior work,
- support engineering decisions,
- guide further reading.

References are not added merely to increase citation count.

---

# Citation Rules

Use citations when:

- introducing established concepts,
- quoting definitions,
- discussing standards,
- presenting research findings,
- comparing alternative approaches.

Do not use citations for:

- obvious engineering observations,
- original proposals,
- implementation details unique to this book.

---

# Citation Style

The project adopts a bibliography-based citation style.

Example:

[Brooks1987]

[Evans2003]

[Fowler2004]

---

# Preferred Sources

Priority order:

1. Standards (ISO, IEEE, RFC)
2. Peer-reviewed papers
3. Academic books
4. Official documentation
5. High-quality technical blogs

Avoid citing:

- anonymous blog posts
- AI-generated content
- social media discussions as authoritative sources
