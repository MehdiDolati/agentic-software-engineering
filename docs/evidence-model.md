# Evidence Model

Every major idea in the book can be associated with one or more evidence types.

| Evidence | Description |
|-----------|-------------|
| Research-backed | Supported by scientific literature or standards |
| Practice-backed | Observed in professional software engineering practice |
| Author Proposal | Original contribution introduced in this book |
| Hypothesis | Requires future validation |

---

# Multiple Evidence Sources

Claims may combine multiple evidence types.

Example:

Context Engineering

Evidence:

✓ Research-backed

✓ Practice-backed

✓ Author Proposal

---

# Confidence Levels

High

- Standards
- Multiple independent studies

Medium

- Multiple industrial reports
- Repeated practical experience

Exploratory

- New engineering ideas
- Author hypotheses

---

# Goal

The objective is not to eliminate original thinking.

The objective is to make the origin of every important idea explicit.
